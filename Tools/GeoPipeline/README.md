# GeoPipeline

Превращает границы стран из Natural Earth в `Nomaded/Resources/Geo/world.nmgeo`. Это готовые 3D-меши стран и контуры для hit-test, которые приложение грузит за доли секунды. Запускается вручную, только когда меняем исходные данные. Результат коммитим.

## Запуск

```bash
curl -L -o "$TMPDIR/ne_usa.geojson" \
  https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_admin_0_countries_usa.geojson
curl -L -o "$TMPDIR/lakes.geojson" \
  https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_lakes.geojson
curl -L -o "$TMPDIR/rivers.geojson" \
  https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_rivers_lake_centerlines_scale_rank.geojson
curl -L -o "$TMPDIR/admin1.geojson" \
  https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_admin_1_states_provinces.geojson

swift run -c release --package-path Tools/GeoPipeline GeoPipeline \
  "$TMPDIR/ne_usa.geojson" Nomaded/Resources/Geo/world.nmgeo \
  --lakes "$TMPDIR/lakes.geojson" --rivers "$TMPDIR/rivers.geojson" --admin1 "$TMPDIR/admin1.geojson" \
  --catalog Nomaded/Resources/Geo/countries.json
```

`--lakes` вырезает из суши ~530 крупнейших озёр и водохранилищ (`LakeCutter.swift`), `--rivers` добавляет ~1 800 рек (`RiverBuilder.swift`). Без этих флагов глобус собирается без них.

`--admin1` собирает виды границ для витрин App Store (`Worldview.swift`, ADR-015): рядом с `world.nmgeo` появляются наложения `world-rus.nmgeo` (Крым, Севастополь, Донецкая, Луганская, Запорожская и Херсонская области → Россия) и `world-chn.nmgeo` (Тайвань и Аруначал-Прадеш → Китай). В наложении только страны, которые вид изменил, их реки и список убранных стран. Регионы берутся из слоя админ-1 Natural Earth: его вершины на границах совпадают с админ-0, поэтому регион вырезается из одной страны и приклеивается к другой отменой общих рёбер (`PolygonDissolver`), без приближений. Пайплайн сам проверяет, что реки остальных стран вышли такими же, как в базе. В `world.nmgeo` пишутся точные контуры спорных регионов с владельцем по умолчанию, в наложения — с владельцем этого вида: по ним приложение отдаёт городу на спорной земле ту страну, которую рисует глобус. Города из справочника на спорной земле получают владельца по умолчанию (крымские у Natural Earth записаны за Россией, на стандартной карте Крым украинский). Natural Earth не обновлялся с мая 2022 года, поэтому его собственные файлы worldview не подходят: переносы прописаны явно.

Результат воспроизводим: два запуска на одних данных дают побайтно одинаковый файл. Всё, что зависит от порядка (перевороты рёбер, склейка озёр), идёт в отсортированном порядке, а не в порядке обхода словаря, который в Swift меняется от запуска к запуску.

Справочник городов для поиска собирается из второго файла Natural Earth:

```bash
curl -L -o "$TMPDIR/places.geojson" \
  https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_populated_places.geojson

swift run -c release --package-path Tools/GeoPipeline GeoPipeline \
  "$TMPDIR/ne_usa.geojson" Nomaded/Resources/Geo/world.nmgeo \
  --lakes "$TMPDIR/lakes.geojson" --rivers "$TMPDIR/rivers.geojson" --admin1 "$TMPDIR/admin1.geojson" \
  --catalog Nomaded/Resources/Geo/countries.json \
  --places "$TMPDIR/places.geojson" --cities Nomaded/Resources/Geo/cities.json
```

`--cities` (`CityCatalogBuilder.swift`): ~7 300 городов с населением, координатами, столицей (`ADM0CAP`, без «alt» вроде Гааги) и названиями en/ru. Города, переименованные после выхода данных Natural Earth (Нур-Султан → Астана, советское «Алма-Ата» → «Алматы»), правит `CityCatalogBuilder.renames`, старое название остаётся в поиске. Дубли Natural Earth (одно имя, один регион, ближе 15 км: два Актау, два Денпасара) склеиваются в один город, больший. Города-близнецы через границу штата (Канзас-Сити) остаются двумя. Места без ISO-кода (Косово, Северный Кипр, Сомалиленд) приписаны стране, в которой их показывает глобус.

`--catalog` пишет справочник для статистики: континент, регион ООН, «одна из 195» и площадь каждой страны (`CountryCatalog.swift`).

Опция `--tolerance 0.02` задаёт степень упрощения границ в градусах (по умолчанию 0.02°, это ~2 км).

После перегенерации прогони тесты: `WorldGeometryTests` проверяют, что ключевые страны на месте, hit-test находит города (и страну у берега при тапе по озеру), озёра вырезаны из суши, реки текут по своей стране и обрываются у озёр, а соседи не одного цвета.

## Что происходит внутри

1. **Чтение** GeoJSON и сборка стран по ISO-коду (`CountryAssembler`). Части с одним кодом объединяются: например, Грузия и регионы, которые в данных идут отдельно. Объекты без ISO-кода (британские базы на Кипре, Бир-Тавиль, Гуантанамо) становятся «ничьей» сушей: она рисуется, но не выбирается. Спорные рифы (Спратли, Скарборо) выбрасываются.
2. **Озёра** (`LakeCutter`, с `--lakes`). Берутся озёра и водохранилища от 300 км² плюс важные по рангу Natural Earth (`scalerank` ≤ 3). Заливы, нарисованные поверх своего озера (Джорджиан-Бей и Норт-Чаннел в Гуроне), выбрасываются. Соседние озёра с общей линией склеиваются, озёра, касающиеся в одной точке, чуть разводятся. Потом каждое озеро вычитается из стран (`PolygonClipper`, Greiner–Hormann): внутри страны оно становится дырой, на границе режется по ней, острова возвращаются суше. Каталог, цвета и города считаются по целым странам, без вырезов. Контуры озёр отдельно пишутся в файл: по ним приложение отличает тап по озеру от тапа по океану.
3. **Упрощение с сохранением топологии** (`TopologySimplifier`). Douglas–Peucker, но общие границы соседей упрощаются одинаково с обеих сторон, поэтому нет щелей и наложений. 545k точек превращаются в ~150k (с озёрами).
4. **Раскраска** (`ColorAssigner`). Каждой стране выдаётся один из 6 цветовых слотов так, чтобы соседи никогда не совпадали.
5. **Триангуляция** (`Earcut`, порт mapbox/earcut). Если упрощение сделало контур крошечного острова самопересекающимся, полигон строится по исходному контуру. Потом рёбра переворачиваются до триангуляции Делоне (`DelaunayFlipper`): earcut, соединяя дыры с контуром, оставляет длинные щепки через всю страну, и каждую потом пришлось бы резать на десятки кусков. Рёбра контура не трогаются, поэтому стыки с соседями остаются без щелей. С этим 530 озёр стоят всего +2% треугольников.
6. **Укладка на сферу** (`SphereMeshBuilder`). Треугольники earcut режутся пополам по длинному ребру в той же плоскости lon/lat, пока рёбра не станут ≤ 1.5° по земле. Так меш повторяет кривизну без трещин и не вылезает за контур. Резать по дуге большого круга нельзя: на севере такая дуга выгибается к полюсу, и треугольники уходят в океан (так у России пропадало арктическое побережье). Длинные прямые границы (49-я параллель) уплотняются, чтобы идти по широте.
7. **Реки** (`RiverBuilder`, с `--rivers`). Набор `scale_rank`: у каждого участка ранг (1 — Амазонка, Нил) и толщина `strokeweig`, растущая к устью. Берутся реки и осевые линии через озёра до ранга 8. Участки склеиваются в непрерывные линии (толщина и ранг — по точкам), части внутри вырезанных озёр выбрасываются, а линия режется по странам. Страна точки берётся из растровой карты стран 0.05°, а короткие (< 40 км) заходы в соседнюю страну — река вдоль границы — остаются за страной вокруг, чтобы линия не прыгала по высоте. Потом упрощение и уплотнение до ≤ 0.5°.
8. **Запись** бинарного файла (`WorldFileWriter`, формат описан в комментарии там же).
9. **Справочник** (`CountryCatalog`, с `--catalog`): континент и подрегион из полей Natural Earth (острова «открытого океана» — по геосхеме ООН), список 195 стран, площадь по исходным контурам на сфере.

## Данные

[Natural Earth](https://www.naturalearthdata.com/) — public domain, разрешено коммерческое использование. Атрибуция не обязательна, но хорошим тоном будет строка «Made with Natural Earth» на экране «О приложении».

Почему именно файл `_usa` (worldview), см. ADR-008 в `docs/03-architecture.md`.
