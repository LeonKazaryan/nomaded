# Nomaded

Личный паспорт путешественника для iPhone. Интерактивный 3D-глобус, на котором страны, где ты был, заливаются яркими цветами. Главное в приложении — живые, «физические» анимации: глобус крутится по инерции, страна при отметке подпрыгивает и заливается волной, вылетают конфетти и штамп паспорта.

> **Статус:** версия 1.0 готова к TestFlight, собирается в Xcode 26.3. Перед отправкой на ревью нужна карточка в App Store Connect. План и чек-листы в [`docs/04-roadmap.md`](docs/04-roadmap.md) и [`docs/06-app-store.md`](docs/06-app-store.md).

## Что умеет

- **3D-глобус на Metal** до 120 кадров в секунду: вращение пальцем с инерцией, зум к точке между пальцами, автовращение в простое. Пока ничего не движется, глобус не рисует ни кадра и не тратит батарею.
- **Карта:** 239 стран и территорий, ~530 озёр, вырезанных из суши, ~1 800 рек. Реки проявляются при приближении и поднимаются вместе со своей страной. Точки для стран, которые слишком малы, чтобы в них попасть: Ватикан, Монако, Мальта, островные государства.
- **Отметка страны:** волна заливки от точки касания, прыжок страны, кольцо по планете, конфетти, штамп паспорта, хаптика. Снятие отметки — спокойная обратная волна.
- **Тап по стране** доворачивает глобус и подстраивает зум под её размер. Поиск стран на любом языке пользователя («США», «UK», «ОАЭ») с перелётом.
- **Города:** офлайн-справочник ~82 000 мест из GeoNames, вместе с курортами, плюс Apple Maps. Поиск мгновенный, на любой раскладке, по старым названиям и с одной опечаткой. Строки одного вида, без дублей, названия на языке приложения. Город сам отмечает свою страну и «приземляется» на глобус. Подписи соседних городов не прячутся: совпадающие объединяются («Рим · Ватикан»), остальные расходятся в стороны.
- **Статистика:** процент мира, континенты с мини-картами, регионы ООН, факты, медали за вехи (10…195 стран, новый континент). Медали снимаются, если отметок стало меньше порога.
- **Онбординг:** прилёт глобуса из гиперпрыжка, быстрый выбор своих стран, итог.
- **Границы по региону App Store:** в России Крым и присоединённые области российские, в Китае Тайвань китайский, в Индии весь Кашмир индийский, в остальном мире — как в Natural Earth (ADR-015).
- **Доступность:** VoiceOver (подписи, озвучка отметок, действия на глобусе), Dynamic Type до AX2, Reduce Motion во всех анимациях. Русский и английский.

| | |
|---|---|

| UI | SwiftUI |

## Как запустить

**В Xcode (основной способ):**

1. Открой `Nomaded.xcodeproj`.
2. Вверху окна выбери схему **Nomaded** и симулятор, например **iPhone 16 Pro**.
3. `⌘R` — запустить, `⌘U` — прогнать тесты, `⇧⌘K` — очистить сборку.

**На своём iPhone:**

0. Xcode должен знать iOS твоего телефона: для iOS 26 нужен Xcode 26. Для загрузки в App Store Connect он нужен в любом случае (см. [`docs/06-app-store.md`](docs/06-app-store.md)).
1. Xcode → Settings → Accounts → твой Apple ID с Apple Developer Program.
2. Проект **Nomaded** → таргет **Nomaded** → **Signing & Capabilities** → **Team** = твоя команда (без пометки Personal Team).
3. Подключи iPhone кабелем, разблокируй и нажми «Доверять этому компьютеру». Выбери телефон вверху вместо симулятора.
4. На iPhone включи Режим разработчика: Настройки → Конфиденциальность и безопасность → Режим разработчика. Пункт появляется после первого подключения к Xcode.
5. `⌘R`.

> Анимации оценивай **только на реальном iPhone**. Симулятор не показывает настоящую плавность (120 Гц) и не умеет в хаптику.

**Из терминала:**

```bash
xcodebuild -project Nomaded.xcodeproj -scheme Nomaded \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro,OS=18.6' build

xcodebuild -project Nomaded.xcodeproj -scheme Nomaded \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro,OS=18.6' test
```

Нужен Xcode 26.3+. Симулятор iOS 26.3 показывает флаги квадратиками «?». Это баг симулятора, на iPhone флаги на месте.

## Инструменты разработчика

Всё это только в Debug-сборке. В App Store этого кода нет (App Review 2.3.1).

- **Зона разработчика:** открой статистику и трижды потяни список за нижний край. Там регион App Store для границ (Авто / Мир / Россия / Китай), счётчик кадров и сброс всего прогресса с онбордингом.
- **Счётчик кадров** в левом верхнем углу: `120 fps`, `30 fps · spin` (автовращение) или `rest` (глобус стоит и ничего не рисует).
- **Launch-аргументы** для сценариев без касаний (полёт к стране, отметка, поиск, онбординг, вид границ). Полный список в [`CLAUDE.md`](CLAUDE.md). Пример:

  ```bash
  xcrun simctl launch "iPhone 16 Pro" com.leonkazaryan.nomaded \
    -NomadedDebugVisited IT,FR -NomadedDebugMark JP
  ```

  С любым `-NomadedDebug…` приложение берёт пустое хранилище в памяти, настоящие отметки не трогаются.

## Данные и иконка

Геоданные и иконка генерируются кодом, руками их не правим:

- [`Tools/GeoPipeline`](Tools/GeoPipeline/README.md) — Natural Earth → `world.nmgeo` (меши стран, озёра, реки, спорные регионы), наложения границ `world-rus.nmgeo`, `world-chn.nmgeo` и `world-ind.nmgeo`, справочники `countries.json` и `cities.nmcity` (города из GeoNames). Результат детерминирован.
- [`Tools/AppIcon`](Tools/AppIcon/README.md) — иконка в трёх видах iOS 18 (обычная, тёмная, тонированная) из настоящих контуров стран.
- [`Tools/Screenshots`](Tools/Screenshots/README.md) — скриншоты для App Store на английском и русском: сцены из самого приложения, подписи и рамка.

Страница поддержки и политика конфиденциальности лежат в `site/` и публикуются на GitHub Pages: https://leonkazaryan.github.io/nomaded/

## Что крутить, если хочется другого ощущения

Все параметры глобуса (трение, пружины, высота подъёма стран, зум, реки, точки микрогосударств, частота кадров на автовращении) лежат в `Nomaded/GlobeEngine/GlobeTuning.swift`. Поменял число, нажал `⌘R` и проверил на телефоне.

Любой файл, который кладёшь в `Nomaded/`, автоматически попадает в проект. Добавлять его в Xcode руками не нужно.
