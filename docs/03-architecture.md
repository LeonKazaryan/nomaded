# 03 · Архитектура

## Стек и почему

| Что | Выбор | Почему |
|---|---|---|
| UI | SwiftUI | Современный стандарт Apple, лучшие встроенные анимации |
| 3D | RealityKit | Будущее 3D у Apple. SceneKit с WWDC25 в soft-deprecated (см. ADR-001) |
| Состояние | `@Observable` (Observation, iOS 17+) | Просто, быстро, без лишних фреймворков |
| Хранение | SwiftData | Нативно, мало кода, позже можно включить синхронизацию через iCloud |
| Графики | Swift Charts | Встроенный, анимируется |
| Поиск городов | MapKit `MKLocalSearchCompleter` | Бесплатно, без ключей и серверов |
| Тесты | Swift Testing | Современный фреймворк тестов, встроен в Xcode 16 |
| Зависимости | нет | Меньше рисков. Новая зависимость только через запись в журнале решений |

### Слои и правила зависимостей

```
Features ──▶ DesignSystem
   │
   ├──────▶ GlobeEngine ──▶ Domain
   │
   └──────▶ Data ─────────▶ Domain
```

- **Domain** ни от чего не зависит: ни SwiftUI, ни SwiftData, ни RealityKit. Чистые типы и функции, полностью покрываются тестами.
- **GlobeEngine** ничего не знает про экраны и SwiftData. Наружу отдаёт маленький API (ниже). Поэтому технологию рендера можно заменить, не трогая фичи.
- **Features** склеивают всё вместе. Логику, которую можно протестировать, выносим из View в Domain.

## Паттерн: «MV» на `@Observable`

Без тяжёлых MVVM/TCA. Для приложения такого размера это лишняя церемония.

- **View** — разметка + локальное UI-состояние (`@State private`).
- **Store** (`@Observable @MainActor final class`) — общее состояние и действия. Передаётся через `.environment(...)`.
- **Domain-функции** — расчёты (статистика, проценты, группировки).

```swift
@Observable @MainActor
final class WorldStore {
    private(set) var visitedCodes: Set<String> = []
    var selectedCountry: Country?

    func markVisited(_ country: Country) { … }   // пишет Visit в SwiftData
    func unmarkVisited(_ country: Country) { … }
}
```

Статистика **никогда не хранится**, она всегда вычисляется из поездок (`StatsCalculator`). Значит, она не может разойтись с данными.

## Модель данных

### `Country` — статический каталог (Domain)
Хранится в бандле приложения (`Resources/countries.json`), пользователь его не меняет.

| Поле | Пример | Заметка |
|---|---|---|
| `id` | `"IT"` | ISO 3166-1 alpha-2, главный ключ везде |
| `alpha3` | `"ITA"` | для связи с геоданными |
| `continent` | `.europe` | enum из 7 |
| `subregion` | `"Southern Europe"` | UN M49 |
| `isSovereign` | `true` | входит ли в 195 (см. определения в 01-product) |
| `centroid` | `(41.9, 12.5)` | куда доворачивать камеру |
| `areaKm2` | `301340` | на будущее (% суши) |

- **Название не храним.** `Locale.current.localizedString(forRegionCode: "IT")` даёт «Италия» / «Italy» / «Italien» на любом языке системы, бесплатно.
- **Флаг** вычисляется из кода (regional indicator symbols → 🇮🇹).

### `Visit` — поездка пользователя (SwiftData `@Model`)

| Поле | Тип | Заметка |
|---|---|---|
| `id` | `UUID` | |
| `countryCode` | `String` | → `Country.id` |
| `startDate` | `Date?` | `nil` = «был, но не помню когда» |
| `endDate` | `Date?` | |
| `cities` | `[String]` | |
| `note` | `String` | |
| `createdAt` | `Date` | для сортировки и «самая свежая» |

- Страна посещена ⇔ у неё есть ≥ 1 `Visit`.
- **Сразу делаем модель совместимой с CloudKit**, чтобы в v1.1 включить iCloud-синхронизацию без миграционной боли: у всех свойств есть значения по умолчанию или они опциональные, никаких `@Attribute(.unique)`, связи опциональные.

## Геоданные

- **Источник:** [Natural Earth](https://www.naturalearthdata.com/) Admin 0 Countries, масштаб **1:50m**. Public domain, можно использовать в коммерческом приложении. 1:110m слишком грубый для маленьких стран, 1:10m слишком тяжёлый.
- **Worldview:** в Natural Earth есть версии границ под разные «точки зрения». Берём дефолтную, решение фиксируем в журнале.
- **Пайплайн (`Tools/GeoPipeline`, M1):** GeoJSON → упрощение → триангуляция → подразбиение крупных треугольников (чтобы следовали кривизне сферы) → проекция на сферу → компактный бинарный файл в `Resources/`. Приложение **не парсит GeoJSON в рантайме**, это медленно. Утилиту запускаем один раз, результат коммитим.
- **Крошечные страны** (Ватикан, Монако, Мальдивы, Науру…) на глобусе почти не видны. Для них делаем точки-маркеры с увеличенной зоной тапа.

## Глобус (`GlobeEngine`)

### Публичный API (черновик)

```swift
@MainActor
protocol GlobeController {
    func setVisited(_ codes: Set<String>, animated: Bool)
    func playVisitCelebration(for code: String)   // заливка + подъём + конфетти
    func focus(on code: String, animated: Bool)   // довернуть страну в центр
    func setHighlighted(_ code: String?)          // выбранная страна
    var onCountryTap: ((String) -> Void)? { get set }
}
```

### Как устроено (план, подтверждаем спайком в M1)
- **Рендер:** `RealityView` с виртуальной камерой (`content.camera = .virtual`, iOS 18). Без AR, просто 3D-сцена.
- **Сцена:** сфера-океан со свечением атмосферы по краю + отдельная сущность (`Entity`) на каждую страну с собственным мешем и материалом. Так каждую страну можно анимировать отдельно: подъём, цвет, свечение.
- **Анимация заливки:** кастомный материал (Metal surface shader через `CustomMaterial` или `ShaderGraphMaterial`) с параметрами «прогресс заливки» и «точка начала». Конкретный способ выбираем в спайке.
- **Жесты:** SwiftUI `DragGesture` / `MagnifyGesture` поверх `RealityView`. Своя физика вращения: ориентация глобуса — кватернион, отпускание даёт угловую скорость с затуханием, фокус на стране — интерполяция кватернионов на пружине. Всё обновляется покадрово (`SceneEvents.Update`).
- **Hit-test математикой, а не через физический движок:** точка экрана → луч из камеры → пересечение со сферой (аналитически) → широта/долгота → кандидаты по bounding box → point-in-polygon. Это детерминированно, быстро и **тестируется юнит-тестами без GPU**.

## Конкурентность (Swift 6)

- Проект в режиме **Swift 6**: компилятор строго проверяет гонки данных.
- Всё, что трогает UI, сторы и RealityKit-сцену, — `@MainActor`.
- Тяжёлое (декодирование мешей, первичная загрузка каталога) — в `async`-функциях вне главного потока, результат возвращаем на main.
- `@unchecked Sendable` и `nonisolated(unsafe)` — только с комментарием, почему это безопасно.

## Журнал решений (ADR)

Каждое значимое решение — строка здесь. Если решение меняется, не удаляем старое, а помечаем «заменено ADR-xxx».

| # | Решение | Статус | Коротко почему |
|---|---|---|---|
| ADR-001 | Глобус на RealityKit, отдельный меш на страну, свой hit-test | **Предложено**, проверяем спайком в M1 | Максимальный контроль над анимацией каждой страны. Запасные варианты: SceneKit (проще анимации, но soft-deprecated с WWDC25) или чистый Metal (максимум контроля, больше работы). MapKit-глобус красивый, но не даёт стилизации и поштучных анимаций стран, то есть убивает наш главный козырь |
| ADR-002 | iOS 18+, только iPhone, только портрет | Принято | `MeshGradient`, zoom-переходы, `RealityView` на iOS. Без iPad проще дизайн и релиз |
| ADR-003 | SwiftData, только на устройстве, модель совместима с CloudKit | Принято | Минимум кода. iCloud включаем в v1.1 без миграций |
| ADR-004 | Без сторонних зависимостей | Принято | Меньше риска для первого приложения |
| ADR-005 | Natural Earth 1:50m как источник границ | Принято | Public domain, адекватная детализация |
| ADR-006 | Swift 6 language mode | Принято | Сразу пишем правильно, без миграции потом |
| ADR-007 | Навигация без `TabView`: глобус как базовый слой + плавающие элементы | Принято | Ощущение «карта и есть приложение», как в Zenly |
