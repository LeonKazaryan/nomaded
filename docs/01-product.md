# 01 · Продукт

## Видение

**Nomaded — это не счётчик стран, а личный паспорт путешественника.**

Открываешь приложение и видишь красивый живой глобус. Крутишь его пальцем, тапаешь Италию, жмёшь **Mark as visited**: страна заливается цветом, приподнимается над планетой, в паспорт ставится штамп, а цифры статистики растут на глазах.

Наш главный козырь — **ощущение**. Функционально похожие приложения уже есть (Been, Visited и другие). Мы выигрываем тем, что Nomaded приятно трогать: каждое действие отвечает движением, цветом и хаптикой. Ориентир по духу — Zenly (Snap закрыл его в 2023-м, и ниша «красивых и игривых» гео-приложений опустела).

## Для кого

- Люди 18–35, которые любят путешествовать и делиться этим.
- Им важно *увидеть* свой мир и похвастаться им, а не вести таблицу.
- Сценарий: отметить страны после поездки, полистать статистику, показать глобус друзьям.

## Главный цикл

```
открыл → крутит глобус → тап по стране → Mark as visited
  → праздничная анимация → статистика выросла → хочется отметить ещё
```

Если этот цикл не вызывает «вау», остальное не важно. Поэтому он делается первым и полируется дольше всего (M4).

## Экраны

### 1. Глобус (главный экран)
- Полноэкранный интерактивный 3D-глобус. Это базовый слой всего приложения.
- Посещённые страны подсвечены яркими цветами, остальные — приглушённые.
- Вращение пальцем с инерцией, pinch для зума, тап по стране.
- Если долго ничего не трогать, глобус медленно вращается сам.
- Поверх плавает компактная карточка **My World**: «27 стран · 12% мира».

### 2. Карточка страны (шторка снизу)
- Появляется по тапу на страну: флаг, название, континент, регион.
- Большая кнопка **Mark as visited** / **Visited ✓**.
- Список поездок в эту страну: даты, города, заметка.
- Добавить поездку: дата (месяц + год, день по желанию) и города.

### 3. My World
- Сколько стран посещено (27).
- Какой процент мира исследован (12%).
- Сколько континентов (5 / 7).
- Сколько посещено городов.
- Самая посещаемая страна.

### 4. Countries
- Список всех стран с флагами, поиском и фильтрами: посещённые / нет, по континенту.
- Дата посещения у каждой посещённой страны.
- Быстрая отметка прямо в списке (удобно в онбординге, чтобы сразу накидать 20 стран).
- История путешествий: все поездки в хронологическом порядке.

### 5. Statistics
- Процент посещённого мира (кольцо / прогресс).
- Топ посещённых регионов (Западная Европа, Юго-Восточная Азия…).
- Самые посещаемые континенты.
- Хронология путешествий по годам.

### 6. Passport (после MVP, v1.2)
- Страницы паспорта со штампами всех стран. Каждый штамп уникальный, с датой первого визита.
- Штамп «ставится» с анимацией в момент Mark as visited (это часть главного вау-момента уже в MVP).

## Скоуп v1.0 (первый релиз в App Store)

**Входит:**
- Глобус: вращение, инерция, зум, тап по стране, подсветка посещённых.
- Mark as visited / Unmark с полной праздничной анимацией.
- Карточка страны и поездки (дата, города, заметка).
- Countries, My World, Statistics.
- Онбординг: эффектный «прилёт» глобуса и быстрый выбор своих стран.
- Праздники за вехи: 10 / 25 / 50 / 100 стран, новый континент.
- Английский и русский языки.
- Всё хранится на устройстве, без аккаунтов и серверов.

**Не входит в v1.0 (сознательно):**
- Аккаунты, друзья, соцсеть, бэкенд.
- Синхронизация через iCloud: сделано в v1.2 (ADR-018).
- Паспорт со штампами как отдельный экран (v1.2).
- Шеринг глобуса в сторис: сделано в v1.2, видео и картинка (ADR-019).
- Виджеты на рабочий стол (v1.3).
- Wishlist («хочу посетить»), ачивки, импорт поездок из геотегов фото (позже).
- iPad, альбомная ориентация. Сделано в v1.1 (ADR-017), на iPhone по-прежнему только портрет.

## Определения (чтобы считать одинаково)

| Термин | Как считаем |
|---|---|
| **Страна** | 195 государств: 193 члена ООН + Ватикан + Палестина. Только они идут в знаменатель «% мира» |
| **Территория** | Гренландия, Пуэрто-Рико, Гонконг и т.п. Есть на глобусе, их можно отметить, но в «% мира» они не входят. Показываем отдельной строкой |
| **Посещённая страна** | Страна, у которой есть хотя бы одна поездка. «Mark as visited» без даты создаёт поездку без даты |
| **% мира** | посещённые страны / 195 |
| **Континенты** | 7: Африка, Антарктида, Азия, Европа, Северная Америка, Океания, Южная Америка |
| **Регион** | Подрегион по классификации ООН M49 («Western Europe», «South-Eastern Asia»…) |
| **Самая посещаемая страна** | Больше всего поездок. При равенстве побеждает та, где был позже всего |
| **Города** | Пользователь добавляет сам, через поиск MapKit (бесплатно, без API-ключей). Считаем уникальные |

## Открытые вопросы

У каждого вопроса есть дефолт, по которому работаем, пока не решим иначе.

1. **«% мира» по количеству стран или по площади?** Дефолт: по количеству. Возможно, позже добавим вторую цифру «% суши».
2. **Спорные территории и границы** (Крым, Тайвань, Кашмир, Косово, Западная Сахара). Дефолт: берём worldview из Natural Earth по умолчанию, а названия стран — системные от Apple. Риски для ревью описаны в [`06-app-store.md`](06-app-store.md).
3. **Точность даты поездки.** Дефолт: месяц + год, день по желанию.
4. **Монетизация.** Дефолт: v1.0 бесплатно и без рекламы. Позже, возможно, Pro: темы глобуса, iCloud, шеринг-карточки.
5. **Тема.** Дефолт: экран глобуса всегда в тёмной «космической» теме. Списки и шторки — тоже тёмные, чтобы не было резких переходов. Обсудим после M2.
6. **Цвета посещённых стран.** Дефолт: у каждой страны свой постоянный цвет из «конфетной» палитры, получается коллекция наклеек. Альтернатива — один цвет для всех.
