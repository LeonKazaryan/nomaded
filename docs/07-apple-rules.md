# 07 · Правила Apple

У Apple два свода правил:
- **Human Interface Guidelines (HIG)** — как приложение должно выглядеть и вести себя. За нарушения напрямую не отклоняют, но ревьюеры замечают, и это влияет на шанс попасть в подборки App Store.
- **App Review Guidelines** — за что приложение отклоняют на ревью.

Плюс технические требования. ✅ значит «уже соблюдено в коде».

## Human Interface Guidelines — что важно для нас

| Правило | Как соблюдаем |
|---|---|
| Зоны касания не меньше 44×44 pt | Кнопка закрытия карточки 44 pt, главная кнопка 54 pt ✅ |
| Dynamic Type | Системные стили шрифтов ✅. Шрифт растёт до AX2: дальше экран с глобусом не вмещает текст. Панели (верхняя, поиск, переключатели) — до xxxLarge, их кнопки показываются крупно по долгому нажатию (Large Content Viewer). Карточка страны, онбординг и итог перестраиваются на крупном шрифте: кнопки друг под другом, «Пропустить» отдельной строкой, однословные названия ужимаются, а не рвутся по слогам ✅ |
| Reduce Motion | Отключаются интро-полёт, автовращение и «подпрыгивание» страны, фон замирает. Выезды и масштабирование карточек, штампа, счётчиков заменены проявлением ✅ |
| VoiceOver | У глобуса есть label, value и hint, плюс действия «Поиск стран», «Посещённые страны», «Статистика»: жестов по глобусу VoiceOver не делает, а всё то же доступно через поиск и списки. Отметка, снятие отметки и новый город озвучиваются (`AccessibilityNotification.Announcement`). У всех кнопок с иконками есть подписи ✅ |
| Хаптика только как подтверждение | Выбор страны — `.selection`, отметка — `.success`. `.sensoryFeedback` сам уважает системные настройки ✅ |
| Делиться через системное меню | Сторис уходят через `ShareLink` (системный share sheet), без своих кнопок соцсетей и чужих SDK ✅ |
| Safe Area | Глобус занимает весь экран, интерактивные элементы внутри safe area ✅ |
| Не перехватывать системные жесты | Не трогаем свайп «домой» снизу и края экрана |
| Тёмная тема | Приложение всегда тёмное (`UIUserInterfaceStyle = Dark`) — это допустимо. Следим за контрастом текста ✅ |
| Системные компоненты, где они есть | Шторки, алерты, меню — системные, а не самописные |
| iPad: многозадачность и окна | Все четыре ориентации и окно любого размера (iPadOS 26), без `UIRequiresFullScreen` (на iPadOS 26 он устарел). Узкое окно получает раскладку iPhone ✅ |
| iPad: указатель и клавиатура | У кнопок hover-эффект по их форме, трекпад крутит и приближает глобус, ⌘F и Esc ✅. Диалоги-поповеры выходят из своей кнопки ✅ |

## App Review Guidelines — риски для нас

| Раздел | Что значит для Nomaded |
|---|---|
| **2.1 App Completeness** | Никаких заглушек, «coming soon», крэшей. Отладочные вещи (FPS-бейдж, launch-аргументы) только под `#if DEBUG` ✅ |
| **2.3.1 Hidden features** | Скрытых функций в сборке для App Store быть не должно. Зона разработчика (смена региона, сброс прогресса) — только `#if DEBUG`, в Release её кода нет: проверено по бинарнику ✅. Переключатель границ в релизе вдобавок нарушал бы законы стран (раздел 5) |
| **2.3 Accurate Metadata** | Скриншоты и видео показывают настоящее приложение. Не обещаем то, чего нет |
| **2.5.1 Public APIs** | Только публичные API Apple ✅ |
| **4.1 Copycats** | Вдохновляемся Zenly, Been, Visited, но не копируем их дизайн, названия и иконки |
| **4.2 Minimum Functionality** | Глобус, поездки и статистика — полноценная ценность ✅ |
| **5.1.1 Data Collection** | Данные не собираем. Синхронизация идёт через личную базу пользователя в iCloud (ADR-018): у разработчика к ней доступа нет, поэтому в App Privacy по-прежнему «Data Not Collected», но политика конфиденциальности про iCloud говорит. Разрешения (геолокация, фото) запрашиваем только в момент, когда они нужны, и с понятным объяснением. Поиск городов идёт через MapKit: разрешений не нужно, запрос уходит в Apple Maps, сами мы его не храним. Сторис делаются на устройстве и уходят только туда, куда их отправит пользователь; «Сохранить видео» в меню просит разрешение только на добавление в «Фото» (`NSPhotoLibraryAddUsageDescription`), читать фото приложение не может. Перед релизом сверить формулировку App Privacy |
| **5.1.2 Data Use** | Нет трекинга, значит не нужен App Tracking Transparency |
| **5.2 Intellectual Property** | Флаги — системные emoji ✅, карты — Natural Earth (public domain) ✅, шрифты системные ✅. Чужих логотипов и брендов нет |
| **5 Legal** (законы стран) | Границы по витрине App Store: ADR-015 в [`03-architecture.md`](03-architecture.md) и раздел 5 в [`06-app-store.md`](06-app-store.md). Китай — только с ICP-регистрацией, Индия — весь Кашмир индийский ✅ |

## Технические требования

- [x] **Privacy Manifest** (`Nomaded/PrivacyInfo.xcprivacy`): трекинга нет, данные не собираем, `UserDefaults` с причиной `CA92.1` (флаг `hasOnboarded` через `@AppStorage`). Лежит в бандле. Новое «API с обоснованием» (дата файла, место на диске, время загрузки системы) — сразу дописывать сюда.
- [x] **Без сторонних SDK** — у каждого свой privacy manifest и подпись. У нас их нет.
- [x] **Экспортное шифрование** — `ITSAppUsesNonExemptEncryption = NO`.
- [x] **Быстрый запуск** — интерфейс появляется сразу, геоданные грузятся асинхронно (~0.3 с в симуляторе). Зависший запуск система убивает.
- [x] **iPhone и iPad, iOS 18+** (ADR-017). Для iPad App Store Connect требует скриншоты 13″ (2064×2752): `Tools/Screenshots/capture.sh ipad`. Ревьюеры проверяют и на iPad. Убрать поддержку iPad в следующих версиях уже нельзя.
- [x] **iCloud (CloudKit)** (ADR-018): права в `Nomaded/Nomaded.entitlements`, `UIBackgroundModes = remote-notification`. TestFlight и App Store пишут в Production-окружение CloudKit, поэтому **до загрузки сборки с новыми полями или сущностями схему выкладывают в Production** (CloudKit Console → Deploy Schema Changes). Иначе синхронизация молча не работает, а приложение выглядит исправным.
- [x] **Строки разрешений** — `NSPhotoLibraryAddUsageDescription` задан в build settings (`INFOPLIST_KEY_…`), перевод в `Resources/InfoPlist.xcstrings`. Без него системное «Сохранить видео/изображение» роняет приложение. Новое разрешение — сразу сюда и в оба `InfoPlist`-перевода.
- [x] **Иконка** — 1024×1024 без прозрачности (M6). Плюс тёмная (прозрачный фон) и тонированная (серая на чёрном) версии iOS 18. Генерирует `Tools/AppIcon`.
- [ ] **Свежий Xcode/SDK** для загрузки в App Store Connect (см. `06-app-store.md`).
