# 05 · Конвенции и процесс

## Код

### Общее
- Следуем [Swift API Design Guidelines](https://www.swift.org/documentation/api-design-guidelines/): понятные имена, без сокращений (`visitedCountries`, а не `vc`).
- Один главный тип на файл, файл называется по типу: `WorldStore.swift`.
- Доступ по умолчанию максимально закрытый: `private`, если не нужно снаружи.
- Комментарии объясняют **почему**, а не **что**. Doc-комментарии (`///`) — для публичного API `GlobeEngine` и неочевидной логики.
- Форматирование — стандартное Xcode (4 пробела). Выделил код → `⌃I`, и Xcode выровняет отступы.
- Код, имена и комментарии — на английском. Документация — на русском.

### SwiftUI
- Маленькие View: если `body` вырос больше ~80 строк, выносим части в подвью.
- `@State` всегда `private`.
- У каждого экрана и компонента есть `#Preview` с тестовыми данными.
- Цвета, шрифты, анимации, хаптика берём **только из DesignSystem** (`Palette.grape`, `Motion.bouncy`). Никаких `Color(red:...)` и `.spring(duration: 0.37)` в коде фич. Исключение — временная заглушка `ContentView`, её заменим.
- Все пользовательские строки — через String Catalog (`Localizable.xcstrings`). `Text("Mark as visited")` попадает туда сам при сборке.
- Проверяй Reduce Motion: `@Environment(\.accessibilityReduceMotion)`.

### Swift 6 и безопасность
- UI, сторы, RealityKit-сцена — `@MainActor`.
- Никаких `try!` и force unwrap (`!`), кроме загрузки ресурсов из бандла при старте. Там `fatalError` с понятным сообщением допустим: битый бандл — это баг сборки.
- API новее iOS 18 — только через `if #available(iOS 26, *)` с фолбэком.

## Git

- `main` всегда собирается и работает.
- Работа в ветках: `feature/globe-spike`, `feature/country-card`, `fix/tap-on-small-countries`.
- Коммиты на английском в стиле [Conventional Commits](https://www.conventionalcommits.org/):
  - `feat(globe): add inertia to drag rotation`
  - `fix(stats): count territories separately`
  - `docs: update roadmap after M1`
  - `chore: bump build number`
- Коммитит **Leon**. Claude пишет код и предлагает текст коммита, но сам не коммитит.
- Релизы помечаем тегами: `v1.0.0`.

### Версии
- `MARKETING_VERSION`: `0.x.y` до релиза, `1.0.0` на релизе, дальше semver.
- `CURRENT_PROJECT_VERSION` (номер билда): +1 при каждой загрузке в TestFlight.
- Меняются в Xcode: таргет **Nomaded** → **General** → Identity.

## Как мы работаем вместе (Leon + Claude)

1. **Берём задачу** — следующий пункт из [`04-roadmap.md`](04-roadmap.md).
2. **Claude коротко описывает подход**, если задача не очевидная. Решает Leon.
3. **Claude пишет код** и сам проверяет, что он собирается и тесты проходят (`xcodebuild`).
4. **Leon запускает на iPhone** и даёт фидбэк по ощущениям: «слишком резко», «хочу больше отскока», «залипает». Для анимаций это главный этап.
5. **Итерируем** параметры (пружины, длительности, цвета), пока не станет «вау».
6. **Обновляем доки:** галочки в роадмапе, новые решения в журнал ADR.
7. **Leon коммитит.**

Если что-то в iOS непонятно (что такое `@MainActor`, зачем `Entity`, почему шторка так себя ведёт), спрашивай. Лучше разобраться сразу, это твоё приложение.

## Шпаргалка по Xcode

| Действие | Как |
|---|---|
| Запустить | `⌘R` |
| Остановить | `⌘.` |
| Тесты | `⌘U` |
| Очистить сборку (когда творится странное) | `⇧⌘K` |
| Быстро открыть файл | `⇧⌘O` |
| Показать/скрыть Preview (Canvas) | `⌥⌘↩` |
| Обновить Preview | `⌥⌘P` |
| Перейти к определению | `⌃⌘J` или `⌘`+клик |
| Документация по символу | `⌥`+клик |
| Консоль / логи | `⇧⌘C` |
| Выровнять отступы | `⌃I` |
| Профилировать (Instruments) | `⌘I` |

**Если Xcode «сошёл с ума»** (ошибки, которых не может быть, Preview не грузится):
1. `⇧⌘K` (Clean Build Folder).
2. Закрыть и открыть Xcode.
3. Удалить DerivedData: Xcode → Settings → Locations → стрелочка у Derived Data → удалить папку проекта.
