## Definition of Done (для любой задачи)
- Собирается без ошибок и **без новых warnings**
- Тесты зелёные, новая логика в Domain покрыта тестами
- Проверено на реальном iPhone (для всего, что анимируется)
- Reduce Motion обработан
- Строки через String Catalog
- Документы обновлены, если поменялось решение или план
