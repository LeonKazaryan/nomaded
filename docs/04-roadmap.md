# 04 · Роадмап

Идём по этапам. Каждый этап заканчивается тем, что приложение собирается, тесты зелёные, а результат проверен на реальном iPhone. Отмечаем `[x]` по мере выполнения.

Самый рискованный кусок, 3D-глобус, делаем **первым** (M1). Если с ним что-то не так, мы узнаем об этом в начале, а не за неделю до релиза.

## M1 — Спайк глобуса (технический риск №1)
Цель: доказать, что выбранный подход (ADR-001) даёт красоту и 120 fps.
- [x] `RealityView` с виртуальной камерой, сфера-океан, свечение атмосферы
- [x] Вращение пальцем 1:1 + инерция + pinch-зум + интро-«прилёт» к своему региону
- [x] `Tools/GeoPipeline`: Natural Earth 1:10m → бинарные меши стран (5.3 МБ, 190k треугольников)
- [x] Все страны на глобусе отдельными сущностями, соседи разного цвета
- [x] Тап → определяем страну (луч–сфера → lat/lon → point-in-polygon) + тесты на реальных городах
- [x] Прототип заливки цветом, подъёма, «прыжка» и хаптики при Mark as visited
- [x] Симулятор: загрузка 0.3 с, 60 fps (потолок симулятора)
- [x] Пайплайн: меш режется в плоскости lon/lat, а не по большим кругам (у России пропадало арктическое побережье) + тест «меш не выходит за контур»
- [x] **Leon:** запуск на iPhone: всё работает, но глобус не выше 60 fps, а в поиске и при выборе страны проседал до 45–58
- [x] Просадки: материал не пересоздаётся каждый кадр (в 70 раз дешевле), стенки стран строятся в фоне, тень стекла только под подложкой
- [x] Глобус переведён на Metal (ADR-010): 120 fps вместо потолка RealityKit в 60
- [ ] **Leon:** повторный замер. Бейдж «N fps · display M» (только в Debug), Instruments → Animation Hitches
- [x] **Решение:** ADR-001 заменён на ADR-010 (Metal)
- [ ] **Решение:** ADR-008 (границы) — можно отложить до M7, но не забыть

## Definition of Done (для любой задачи)
- Собирается без ошибок и **без новых warnings**
- Тесты зелёные, новая логика в Domain покрыта тестами
- Проверено на реальном iPhone (для всего, что анимируется)
- Reduce Motion обработан
- Строки через String Catalog
- Документы обновлены, если поменялось решение или план
